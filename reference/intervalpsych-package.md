# The 'intervalpsych' package.

The intervalpsych package provides tools for analyzing continuous
bounded interval responses in psychometrics. It implements the Interval
Consensus Model (ICM, Kloft et al., 2024), which is a consensus model
for such data.

## References

Kloft, M., Siepe, B. S., & Heck, D. W. (2024). The Interval Truth Model:
A Consensus Model for Continuous Bounded Interval Responses.
[doi:10.31234/osf.io/dzvw2](https://doi.org/10.31234/osf.io/dzvw2)
