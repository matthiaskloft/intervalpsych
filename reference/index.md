# Package index

## Transformation functions

Transformation functions for interval data.

- [`ilr()`](https://matthiaskloft.github.io/intervalpsych/reference/log_ratio_transformations.md)
  [`slr()`](https://matthiaskloft.github.io/intervalpsych/reference/log_ratio_transformations.md)
  : Log-Ratio transformations for interval responses
- [`inv_ilr()`](https://matthiaskloft.github.io/intervalpsych/reference/inv_log_ratio_transformations.md)
  [`inv_slr()`](https://matthiaskloft.github.io/intervalpsych/reference/inv_log_ratio_transformations.md)
  : Inverse Log-Ratio transformations for interval responses
- [`itvl_to_splx()`](https://matthiaskloft.github.io/intervalpsych/reference/itvl_to_splx.md)
  : Convert from interval bounds to simplex
- [`splx_to_itvl()`](https://matthiaskloft.github.io/intervalpsych/reference/splx_to_itvl.md)
  : Convert from simplex to interval bounds
- [`remove_zeros()`](https://matthiaskloft.github.io/intervalpsych/reference/remove_zeros.md)
  : Remove Zeros from Simplex
